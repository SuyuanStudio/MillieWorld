# Hi! Welcome to MillieWorld-A magical world to Learn&Create!

米粒苏/米粒世界是一个制作各种原创角色、视频、图片和设计的项目。
它的其中一个名字“米粒苏”将作者的英文名Millie跟广州的一个叫“苏元”的地铁站结合在了一起。
这个项目的初衷就是用中国原创角色将中国文化展示给全世界。
MillieSu/MillieWorld is a create project that make various of original characters,videos,images and designs.
One of its name "MillieSu" combines the creator's English name Millie with a metro station in Guangzhou called Suyuan.
This project's purpose is spreading Chinese cultures to the world by representing Chinese original character arts.

#关于企划项目 About the types of projects
本仓库为MillieWorld主仓库，存放米粒世界世界观与项目吉祥物相关内容。
其余企划如中国地铁少女、小浔历险记、魔法战士等，分别放置在独立子仓库。想要浏览这些世界观的内容，欢迎移步至对应的子仓库查看。
企划产出包含原创角色设定、世界观故事、插画、短片与视觉设计。所有角色与美术作品均为独立原创，融入广州本土特色与中华文化元素。不同世界观各自拥有独立设定，互不干扰。
This repository is the main repository for MillieWorld, hosting the MillieWorld worldbuilding and project mascot materials.
Other projects including China Metro Girls, Xiaoxun, MagicalSoldiers and more are stored in separate sub-repositories. Please visit the corresponding sub-repositories if you want to explore these worlds.
Deliverables include original character sheets, worldbuilding stories, illustrations, short videos and visual design. All characters and artworks are independently created, integrating local Guangzhou features and Chinese cultural elements. Each world has its own separate settings and does not interfere with others.
